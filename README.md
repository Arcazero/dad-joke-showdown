One original one-line dad joke — an entry for make.fun's "Dad Joke Showdown" bounty ($5 in USDC).

## The joke

> I told my wife she should embrace her mistakes. She gave me a hug.

66 characters, one line. The full line also lives in `joke.txt`.

## Run it

```sh
python3 main.py
```

`main.py` writes the joke to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output/entry.txt`), which is what the bounty judge reads. No network, no dependencies, deterministic.
